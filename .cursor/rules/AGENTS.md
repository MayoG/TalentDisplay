## Project

A modern, cinematic portfolio website for a theater actress.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion for subtle animations

## Design Direction

The site should feel like a modern theater portfolio:

- cinematic
- elegant
- dramatic
- emotional
- personal
- minimal

Avoid:

- corporate startup look
- dashboard UI
- generic SaaS design
- bright playful colors
- heavy component-library feeling

## Visual Style

Use a dark cinematic style:

- black / charcoal background
- warm white text
- deep burgundy accents
- subtle gold accents
- large photography
- spacious layout
- soft shadows
- spotlight-like gradients

## Typography

Use elegant typography:

- Serif font for headings
- Clean sans-serif font for body text
- Large expressive hero title
- Strong spacing and line height

Suggested pairing:

- Playfair Display for headings
- Inter for body text

## Page Flow

Build a single-page website with these sections:

1. Hero
2. About
3. Featured Roles
4. Gallery
5. CV / Resume
6. Contact

## UX Rules

- Mobile-first responsive design
- Smooth scrolling
- Subtle fade/slide animations
- Slow image hover zooms
- Clear navigation
- Accessible contrast
- Do not over-animate

## Code Rules

- Use small reusable components
- Keep content in data files when possible
- Use TypeScript types for props and data
- Avoid unnecessary dependencies
- No backend
- No database
- No authentication

## Content Rules

Use placeholder content for now, but make it easy to replace:

- actress name
- bio
- role names
- theater names
- years
- CV / resume PDF
- contact details
- images
